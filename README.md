# Future-Proof Career Roadmap — Web Tracker

This is the interactive Web UI for the **Future-Proof Career Roadmap (Backend + AI + Cloud Native Architect)**. It allows you to visualize your career progression, jump instantly between learning phases via an active scrolling sidebar, and read detailed verification guides for 63 high-leverage topics.

## 🚀 Features
- **SaaS Dashboard Theme**: Premium dark-mode gray and clean blue branding.
- **Interactive Checklists**: Click on topics to toggle completion rates, dynamically updating overall stats.
- **Sidebar Table of Contents**: Easily navigate between phases without continuous scrolling.
- **Detailed Reference Guides**: Pop up goals, coding exercises, checklists, and learning resources.
- **Persistence**: Checked items are persistently saved locally in your browser's storage.

## 🛠️ Tech Stack
- **Structure**: HTML5
- **Style**: Custom Vanilla CSS3
- **Logic**: Custom Vanilla JavaScript
